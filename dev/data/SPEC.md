# 「国旗から」国データ作成の仕様

小学生の娘が使う国旗暗記アプリ（iPad）の国カード用データを作る。読み手は子ども。正確さが最優先。

## 出典
- 数値（人口・面積）、首都、正式名称、言語、宗教、通貨は **外務省「国・地域」の各国「基礎データ」ページ** を出典にする。
  - 一覧: https://www.mofa.go.jp/mofaj/area/index.html
  - 各国: 多くは https://www.mofa.go.jp/mofaj/area/<英字名>/data.html （例: france, usa, china, kenya）
  - URLが分からない時は WebSearch で「外務省 <国名> 基礎データ」。
- 外務省にページがない地域（香港・マカオ・グリーンランドなど）は、政府統計など信頼できる公式の出典を使い、その URL を source に書く。
- 推測で数字を埋めない。どうしても確認できない項目は check に書く。

## 出力
指定のパスに **JSON 配列**（1国1オブジェクト）を書く。UTF-8。JSON として正しいこと（node で JSON.parse できるか確かめる）。

| キー | 型 | 内容 |
| --- | --- | --- |
| code | 文字列 | 指定された2文字コード（そのまま） |
| kind | 文字列 | "country" か "region"（リストで [地域] と付いたものは region） |
| name | 文字列 | ふだん使う国名（外務省の表記。例: アメリカ合衆国→「アメリカ」、英国→「イギリス」）。漢字を含むときは {漢字|よみ} 形式でふりがな（例: {中国|ちゅうごく}、{南|みなみ}スーダン、{香港|ホンコン}）|
| official | 文字列 | 外務省の正式名称。漢字は {漢字|よみ} 形式（例: フランス{共和国|きょうわこく}） |
| aliases | 文字列配列 | 声で答えたときに正解にする言い方。カタカナの読み（・なし）、表記ゆれ、漢字表記を入れる。略称は入れない（「ブルキナ」は不可）。例: ["アメリカ","アメリカガッシュウコク","アメリカ合衆国","ベイコク","米国"] |
| capital | 文字列 | 首都（外務省の表記）。漢字は {漢字|よみ}（例: {北京|ペキン}） |
| pop | 数値 | 人口（人。例: 68000000）。外務省の値 |
| popYear | 文字列 | その人口の年と出どころ（例: "2023年 世界銀行"）。外務省に書いてある通り |
| area | 数値 | 面積（km²）。外務省の値 |
| langs | 文字列配列 | おもな言語（多い順・最大4つ。例: ["フランス語"]）。ふりがな不要 |
| langMore | 真偽 | 4つ以外にも公用語・主要言語があれば true |
| rels | 文字列配列 | おもな宗教のキー（多い順・最大2つ）: christ（キリスト教）, islam, buddha, hindu, judaism, shinto, none（無宗教の人が多い）, folk（伝統的な宗教・その他） |
| money | 文字列 | 通貨（例: "ユーロ", "ケニア・シリング"） |
| hello | 文字列 | その国のおもな言葉の「こんにちは」をカタカナで（例: "ボンジュール"） |
| helloSay | 文字列 | 同じあいさつを現地の文字で（例: "Bonjour"） |
| helloLang | 文字列 | 読み上げ用の言語コード（例: "fr-FR"） |
| meaning | 文字列 | 国旗の色や形の意味を1〜2文（60字以内）。子どもに分かる言葉で、広く認められた説明だけ。ふりがな不要（あとで自動で付ける） |
| trivia | 文字列 | 子どもが「へえ！」と思う豆知識を1文（45字以内）。自然・動物・食べ物・名所・世界一など。政治・戦争・事件・宗教対立は書かない。ふりがな不要 |
| feat | 文字列配列 | 国旗の特徴タグ: star（星）, circle（丸・太陽・月以外の円）, moon（三日月・月）, cross（十字）, uj（イギリス国旗が入っている）, vtri（縦3つに分かれる）, htri（横3つに分かれる）, two（使っている色が2色だけ）, emblem（紋章・絵・文字が入る）, triangle（三角がある） |
| similar | 文字列配列 | 子どもが間違えやすい、よく似た国旗の国コード（0〜4個）。下の「全体リスト」のコードから選ぶ（自分の担当外の国も可） |
| twins | 文字列配列 | 見た目がほぼ同じで区別できない国旗（例: ID と MC、TD と RO）。なければ [] |
| note | 文字列 | 地域だけ: 立場を事実だけで1文（例: "日本は国として承認していない。"、"中国の特別行政区。"、"デンマークの自治領。"）。国は "" |
| source | オブジェクト | {"url": 使った外務省ページのURL, "title": "外務省 <国名>基礎データ"} |
| check | 文字列 | 確認しきれなかった点（なければ ""） |

## 書き方の注意
- 書き方の見本は /home/claude/kokki/countries.js（既存50か国。{漢字|よみ} はふりがな）。既存の国が担当にあれば、meaning・trivia・hello などはそこから流用してよい（ただし meaning/trivia はふりがなを外した普通の文に直す）。数値・首都・言語・宗教・通貨は必ず外務省で確認し直す。
- 文は「です・ます」ではなく「〜だ／〜である」調でもなく、既存と同じ短い言い切り（例: 「赤は勇気、白は平和を表す。」）。
- 全体リスト（similar に使えるコード）: /home/claude/kokki/master.json の code。
